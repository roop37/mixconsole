# MixConsole

MixConsole analyzes local audio and stores editable, versioned MixScripts.
M0/M1 analysis, M1R robustness, M1H hardening and M2 two-song mixing are
implemented. HTTP jobs and the web console remain future work.

Start with the [quickstart](quickstart.md), learn the [concepts](concepts.md), or
inspect the [contract](mixscript.md) and [benchmarks](benchmarks.md).

The core runs offline without torch, a GPU, or model weights. Synthetic accuracy
results are not evidence of real-music or listening quality.
