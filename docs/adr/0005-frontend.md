# 0005: React, Vite and generated TypeScript

Status: Accepted; implemented in M5 (`apps/console`).

## Context

An editable local console needs typed contracts and independent preview controls.

## Decision

Use React/Vite/TypeScript in apps/console. Generate types from Python schemas and OpenAPI into packages/schema-ts.

## Consequences

No UI code in M1H. Generator selection and drift gates accompany the M4.5 API; no handwritten API type duplicates.

## M5 notes

- Types: the OpenAPI types and the MixScript v1.1 document types are both generated by
  `scripts/gen_api_types.py` (drift-checked in `check.sh`); the console casts the opaque
  `document` JSON to the generated `MixScript` type in one place (`lib/mixscript.ts`).
- The built app is static and served by `mixconsole serve --ui` from the same origin as the API.
- Local-first: no telemetry, no external fonts or CDNs; the per-run token travels in the URL once,
  is moved to `sessionStorage` and removed from the address bar.
