## Decisions and deviations

- ADR 0008 records the schema, job and API design. TypeScript types come from a Python emitter
  (`scripts/gen_api_types.py`), not `openapi-typescript`: Node/pnpm exist here, but a Python emitter keeps the drift check
  inside `check.sh` with no JS install. The emitter is intentionally small (OpenAPI 3.1 subset FastAPI produces).
- Jobs run as threads in the server process (the facade supplies the process pool); there is no separate worker process.
- `mix` (full pipeline, `mix_pair`) and `render` (saved MixScript version) are separate job kinds; the brief's "plans,
  renders" are `plans`/`mixscripts` and `mixes`/`renders`.
- Project track ids are file-content hashes, so the same bytes at two paths are one track (path updated to the latest add).

## Limits

- Single local user: single-writer SQLite, no multi-user auth, token regenerated on every server start.
- RAM costs per job kind are fixed estimates; a native crash in a job takes the server process down.
- Library scan identifies unchanged files by path/size/mtime (a same-size, same-mtime edit is not noticed).
- `/docs` and `/openapi.json` need no token (no user data); stems still follow `MIXCONSOLE_STEMS` (default off).
- Preview of a whole track is encoded on first request (can take a few seconds for long files).
- The 100-track test is marked `slow` (about 25 s) and is not in `check.sh`.
