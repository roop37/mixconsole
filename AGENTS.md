# AGENTS.md — rules for AI coding agents (Codex, Claude, others)

Read `PLAN.md` (architecture, principles) and `ROADMAP.md` (milestones) before changing anything.

## Hard rules
- Work only on the milestone you were given. Record evidence in `planning/Mxx-*.md` (commands run, results, paths).
- `scripts/check.sh` must pass before you finish (ruff, ruff format --check, pyright, pytest -m "not slow").
- **Clean-room:** never copy code from GPL/LGPL/AGPL projects (e.g. VertexSelection/automix-engine, Rubber Band, Essentia,
  madmom models, libKeyFinder). Reading papers and docs is fine. GPL tools may only be called as external processes, behind an optional backend.
- Every new dependency or model weight → add it to `THIRD_PARTY.md` with license + URL. No non-commercial weights as defaults.
- Never commit audio except tiny synthetic fixtures generated by code. Never commit model weights.
- No AI attribution in commits, PRs or files (no Co-Authored-By, no "Generated with ...").
- Conventional commits: `feat(analysis): ...`, `fix(render): ...`, `test: ...`, `docs: ...`, `chore: ...`.
- Determinism: seed everything; same input + MixScript ⇒ identical output bytes.
- Core package (`mixconsole` without extras) must import and run with no torch / no GPU.

## Layout
```
src/mixconsole/
  io/          decode, resample, write, content hashing
  analysis/    backends (beats, key, loudness, sections, cues, vocals, stems) + cache
  mixscript/   schema (JSON Schema + pydantic models), validation, migrations
  plan/        candidate generation, families/, constraints
  score/       heuristic scorer (weights.yaml), later learned ranker
  render/      DSP graph: gain, eq, filters, delay, stretch, limiter
  verify/      seam metrics + thresholds + fallback
  report/      report.json + report.html
  cli.py       Typer app
tests/         unit, property (hypothesis), synthetic fixtures (tests/synth.py)
bench/         corpus manifests, runners, results
ui/            (M5) web console
planning/      milestone evidence
```

## Commands
- Setup: `uv sync --all-extras --dev` (or `uv sync --dev` for core only)
- Check: `scripts/check.sh`
- Slow/model tests: `uv run pytest -m slow`
